# Uso de Inteligencia Artificial Generativa y Gestión de Prompts

---

# 1. Introducción

## 1.1 Objetivo

El presente documento describe el uso de herramientas de Inteligencia Artificial Generativa (IA Generativa) como apoyo técnico durante el desarrollo de la Plataforma Centralizada de Gestión y Distribución de Contenido Multimedia Formativo.

La utilización de IA tuvo como finalidad acelerar procesos de desarrollo, mejorar productividad técnica y optimizar actividades repetitivas dentro del ciclo de vida del software.

---

# 2. Objetivos del Uso de IA

La adopción de herramientas de IA Generativa tuvo como principales objetivos:

- Reducir tiempos de desarrollo.
- Acelerar construcción de componentes.
- Facilitar generación de documentación.
- Optimizar configuraciones técnicas.
- Apoyar resolución de problemas.
- Estandarizar estructuras base.
- Mejorar productividad del equipo técnico.

---

# 3. Alcance del Uso de IA

La IA Generativa fue utilizada como herramienta de apoyo técnico y acelerador de productividad.

## Áreas donde fue utilizada

| Área | Uso |
|---|---|
| Backend | Generación estructuras base |
| Frontend | Construcción componentes |
| DevOps | Dockerfiles y pipelines |
| APIs | DTOs y endpoints |
| Streaming | Comandos FFmpeg |
| Documentación | Generación técnica |
| Seguridad | Configuraciones base |
| Operaciones | Scripts y troubleshooting |

---

# 4. Herramientas de IA Utilizadas

La plataforma fue desarrollada utilizando herramientas modernas de asistencia basada en IA Generativa.

## Herramientas utilizadas

| Herramienta | Objetivo |
|---|---|
| ChatGPT | Asistencia técnica |
| GitHub Copilot | Autocompletado código |
| IA Conversacional | Generación documentación |
| Motores LLM | Optimización prompts |

---

# 5. Estrategia de Uso de IA

La IA no reemplazó el análisis técnico ni las decisiones arquitectónicas.

## Principios aplicados

- Supervisión humana obligatoria.
- Validación técnica manual.
- Revisión de seguridad.
- Adaptación contextual.
- Refinamiento iterativo.

---

# 6. Ingeniería de Prompts

## 6.1 Definición

La ingeniería de prompts consiste en construir instrucciones estructuradas y contextualizadas para obtener resultados técnicos más precisos desde herramientas de IA.

---

# 7. Objetivos de la Ingeniería de Prompts

La estrategia de prompts buscó:

- Obtener respuestas técnicas más exactas.
- Estandarizar generación de código.
- Reducir ambigüedad.
- Acelerar construcción de componentes.
- Facilitar documentación técnica.
